Практическая работа № 6
Тема: адаптивный сайт онлайн-курсов WebCraft на Bootstrap 5.

Как открыть проект:
1. Распакуйте архив в отдельную папку.
2. Откройте файл index.html в браузере.
3. Для работы сайта оставьте папки css и js рядом с index.html.

В проекте используются компоненты Bootstrap 5:
- Navbar и Collapse - навигация и мобильное меню;
- Grid - адаптивная сетка;
- Card и Badge - карточки курсов;
- Alert - информационное сообщение;
- Progress - индикатор плана обучения;
- Nav Pills и Tab - вкладки об обучении;
- Carousel - примеры учебных проектов;
- Accordion - частые вопросы;
- Modal - короткая форма записи;
- Form Validation - проверка заполнения формы;
- Toast - уведомление после отправки;
- Tooltip - всплывающая подсказка.

Bootstrap подключён локально, интернет для загрузки стилей и скриптов не нужен.
Формы демонстрационные: данные не отправляются на сервер.
